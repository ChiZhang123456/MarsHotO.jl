# Rahmati COM Scattering Angle and Two Body Collisions

## 1. Scattering angle distribution used by the current model

MarsHotO uses the model described in Sections 2.2.3 and 2.2.4 of the Rahmati dissertation. It adopts an analytical fit to the O and O differential collision cross section calculated by Kharchenko et al.:

```math
\frac{d\sigma}{d\Omega}
=
\alpha\sin^\beta
\left(\frac{\theta_{\mathrm{COM}}}{2}\right),
```

with

```math
\alpha
=
0.36\times10^{-16}\ \mathrm{cm^2\,sr^{-1}},
\qquad
\beta=-1.85.
```

Here $\theta_{\mathrm{COM}}$ is the scattering angle in the center of mass frame. The current model applies the same functional form of the COM angular distribution to collisions between O and every neutral target species.

## 2. Why the probability contains $\sin\theta$

The differential cross section is defined per unit solid angle. In spherical coordinates,

```math
d\Omega
=
\sin\theta\,d\theta\,d\phi.
```

Therefore, the one dimensional probability density of the COM polar angle is not simply $d\sigma/d\Omega$. It is

```math
p(\theta)
\propto
\frac{d\sigma}{d\Omega}\sin\theta.
```

After substituting the Rahmati fit and normalizing,

```math
p(\theta)
=
\frac{\beta+2}{2}
\sin^{\beta+1}
\left(\frac{\theta}{2}\right)
\cos\left(\frac{\theta}{2}\right),
\qquad
0\le\theta\le\pi.
```

Although the probability density is large near zero angle, the integral beginning at $0^\circ$ remains finite because

```math
\beta+2=0.15>0.
```

## 3. CDF and inverse transform sampling

Integration from zero to $\theta$ gives the cumulative distribution

```math
F(\theta)
=
\sin^{\beta+2}
\left(\frac{\theta}{2}\right).
```

The computer generates a uniform random number

```math
R\sim\mathcal U(0,1).
```

Setting $R=F(\theta)$ and solving for $\theta$ gives

```math
\boxed{
\theta_{\mathrm{COM}}(R)
=
2\arcsin
\left[
R^{1/(\beta+2)}
\right]
}.
```

Because

```math
\frac{1}{\beta+2}
=
\frac{1}{0.15}
\approx6.667,
```

most random numbers produce small COM scattering angles. The angle approaches $180^\circ$ rapidly only when $R$ is very close to 1.

If a nonzero minimum angle is required in a future implementation, the general inverse transformation is

```math
\theta(R)
=
2\arcsin
\left\{
\left[
R(1-C_{\min})+C_{\min}
\right]^{1/(\beta+2)}
\right\},
```

where

```math
C_{\min}
=
\sin^{\beta+2}
\left(\frac{\theta_{\min}}{2}\right).
```

The current implementation uses $C_{\min}=0$.

## 4. Rahmati energy loss relation

Equation 2.19 of the Rahmati dissertation gives the fractional energy loss of the incident hot O:

```math
\boxed{
\frac{\Delta E}{E}
=
\frac{2m_{\mathrm O}m_s}
{(m_{\mathrm O}+m_s)^2}
\left(1-\cos\theta_{\mathrm{COM}}\right)
}.
```

Here $m_{\mathrm O}$ is the mass of the incident O atom and $m_s$ is the mass of the neutral target. The angle generated by the inverse transformation is already a COM angle, so it can be inserted directly into this relation without a LAB to COM angular conversion.

For an O and O collision,

```math
\frac{\Delta E}{E}
=
\frac{1}{2}
\left(1-\cos\theta_{\mathrm{COM}}\right)
=
\sin^2
\left(\frac{\theta_{\mathrm{COM}}}{2}\right).
```

Thus, a COM angle of $90^\circ$ transfers 50 percent of the incident energy, while a COM angle of $180^\circ$ transfers 100 percent.

## 5. Transformation from COM to the Mars stationary frame

The precollision center of mass velocity is

```math
\mathbf V_{\mathrm{COM}}
=
\frac{
m_{\mathrm O}\mathbf v_{\mathrm O}
+
m_s\mathbf v_s
}{
m_{\mathrm O}+m_s
}.
```

The current model uses the stationary target approximation:

```math
\mathbf v_s=0.
```

The precollision relative velocity is

```math
\mathbf g
=
\mathbf v_{\mathrm O}-\mathbf v_s.
```

The code rotates $\mathbf g$ using the sampled $\theta_{\mathrm{COM}}$ and a uniform azimuth $\phi$, producing $\mathbf g'$. Elastic scattering preserves the magnitude of the relative velocity:

```math
|\mathbf g'|=|\mathbf g|.
```

The postcollision velocities in the Mars stationary frame are

```math
\mathbf v_{\mathrm O}'
=
\mathbf V_{\mathrm{COM}}
+
\frac{m_s}{m_{\mathrm O}+m_s}\mathbf g',
```

```math
\mathbf v_s'
=
\mathbf V_{\mathrm{COM}}
-
\frac{m_{\mathrm O}}{m_{\mathrm O}+m_s}\mathbf g'.
```

These relations conserve both linear momentum and total kinetic energy.

## 6. Secondary hot O

When the target is O, the postcollision velocity $\mathbf v_s'$ belongs to a recoil O atom. If its energy exceeds the minimum tracking energy, the program adds it to the particle queue as a secondary hot O atom. It inherits the same macroparticle rate weight as its parent.

## 7. Calculation sequence for one collision

1. Use the neutral densities and total cross sections to determine whether a collision occurs.
2. Select the target species with probabilities proportional to $n_s\sigma_s$.
3. Generate a uniform random number $R$.
4. Use the inverse CDF to obtain $\theta_{\mathrm{COM}}$.
5. Independently sample a uniform azimuth $\phi$.
6. Rotate the relative velocity in COM.
7. Transform to the Mars stationary frame and obtain the postcollision velocities of both particles.
8. Continue tracking the incident hot O in the Mars stationary frame.
9. If the target is O, track the recoil secondary O when required.

## 8. Current approximations

1. Collisions with different neutral species share the angular fit derived from the Kharchenko O and O calculation.
2. Neutral target particles are stationary before collision.
3. Species specific, energy dependent differential cross sections should replace the common angular distribution when they become available.
